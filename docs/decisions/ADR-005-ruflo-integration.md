# ADR-005: Ruflo Integration

Status: pending upstream review.

Task 1 defines `integrations/ruflo` as a future optional orchestration adapter boundary. PolyMind does not copy Ruflo code or fabricate API calls. Upstream repository URL, license, and reviewed commit/tag remain pending until live upstream inspection is performed.

Decision direction: keep council, workflow, and swarm-style execution as extension modes over the PolyMind execution engine rather than making Ruflo core infrastructure.
